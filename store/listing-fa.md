# لیستنگ فارسی — SpiMp3

متن‌های آمادهٔ فرم ثبت در مایکت. محدودیت مایکت معمولاً ۴۰۰۰ کاراکتر برای توضیحات است.

## نام برنامه

```
SpiMp3
```

## توضیح کوتاه (حداکثر ۸۰ کاراکتر)

```
پخش‌کنندهٔ موسیقی آفلاین، سریع و سبک
```

## توضیحات کامل

```
SpiMp3 یک پخش‌کنندهٔ موسیقی کاملاً آفلاین است: هیچ اینترنتی، هیچ تبلیغی، هیچ
ردیابی. فقط آهنگ‌های خودتان، دقیقاً همان‌طور که روی گوشی‌تان هست.

• پخش همهٔ فرمت‌های صوتی پشتیبانی‌شده توسط اندروید (MP3، M4A، FLAC، OGG، WAV و …)
• رابط کاربری تیره و مینیمال، بدون شلوغی و تبلیغ
• جست‌وجوی سریع در نام آهنگ، هنرمند و آلبوم
• فیلتر بر اساس آهنگ، آلبوم، هنرمند و پوشه
• پلی‌لیست بسازید، تغییر نام دهید، حذف کنید و جابه‌جا کنید
• علاقه‌مندی‌ها و تاریخچهٔ پخش
• تکرار (Loop)، تصادفی (Shuffle) و ترتیب سفارشی
• تایمر خواب: بعد از چند دقیقه یا در پایان صفحهٔ پخش، پخش متوقف شود
• پخش در پس‌زمینه با کنترل از صفحهٔ اعلان و صفحهٔ قفل
• نمایش نوار پیشرفت و زمان، با کنترل‌های درشت و راحت برای کار با یک دست

حریم خصوصی
SpiMp3 هیچ داده‌ای جمع‌آوری یا ارسال نمی‌کند. اپ به اینترنت دسترسی ندارد مگر
برای یک بررسی اختیاری نسخهٔ جدید که خودتان می‌توانید در تنظیمات خاموشش کنید.
هیچ تبلیغ، تحلیل یا شبکهٔ اجتماعی‌ای در کار نیست.

پشتیبانی
اگر مشکلی دیدید یا ایده‌ای دارید، خوشحال می‌شویم بشنویم:
https://github.com/ciomid1097-arch/SpiMp3/issues
```

## پاسخ به پرسش‌های متداول داور

**«چرا مجوز `INTERNET` دارید؟»**
برای بررسی اختیاری وجود نسخهٔ جدید در GitHub Releases. این قابلیت در
Settings → Updates خاموش می‌شود و هیچ داده‌ای ارسال نمی‌کند.

**«آیا برنامه داده‌ای جمع‌آوری می‌کند؟»**
خیر. هیچ کتابخانهٔ تحلیلی، تبلیغاتی یا شبکهٔ اجتماعی در برنامه وجود ندارد.
تنها دسترسی‌ها: خواندن فایل‌های صوتی، اعلان‌ها، و اینترنت فقط برای بررسی آپدیت.

**«آیا فایل اجرایی دیگری ارائه می‌کنید؟»**
خیر.
